# RSBUILD brand assets

This directory contains the code-facing brand layer used by RSBUILD Finance.

## Current repository contents
- `rsbuild-network-pattern.svg` — decorative nodes-and-connections background pattern.
- `rsbuild-logo-primary.webp` — primary RSBUILD logo lockup exported from page 7 of the approved PDF guide for the login UI.
- `tokens.css` and `tokens.json` — canonical palette, typography, and gradient tokens.
- `kit/README.md` — reusable kit structure and export instructions.

## Source and provenance
The current primary logo export was recovered from page 7 of the approved RSBUILD Visual Identity Guide PDF. It is suitable for the login UI but is a raster WebP export, not the original editable vector master.

The PDF also documents the secondary logo and the 14-icon library. The original vector logo masters, alternate white lockups, and individual icon exports should be added only from the verified source package when available. Never redraw the official logo or substitute a screenshot.

See `docs/BRAND_ASSETS.md` and `docs/BRAND_KIT_EXPORT.md` for usage, accessibility, provenance, and cross-product reuse.
