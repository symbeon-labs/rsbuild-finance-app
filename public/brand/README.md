# RSBUILD brand assets

This directory contains the code-facing brand layer used by RSBUILD Finance.

## Current repository contents
- `rsbuild-network-pattern.svg` — decorative nodes-and-connections background pattern.
- `tokens.css` and `tokens.json` — canonical palette, typography, and gradient tokens.
- `kit/README.md` — reusable kit structure and export instructions.

## Full production export
The separately delivered RSBUILD production kit contains:
- primary and secondary logo lockups with transparent backgrounds;
- white logo variants for dark surfaces;
- 14 individual icons in SVG and PNG;
- the complete vector pages and original guide for provenance.

Those binary/vector files have not yet been copied into this repository. When installing them, preserve the original filenames and place them under `logo/` and `icons/`. Never redraw the official logo or substitute a screenshot.

See `docs/BRAND_ASSETS.md` and `docs/BRAND_KIT_EXPORT.md` for usage, accessibility, provenance, and cross-product reuse.
